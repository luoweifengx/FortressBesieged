# 围城集群

世界里会出现哪种军队，由**阶段**决定；军队长什么样，由**模板**决定。

配置文件两份，阶段表和模板都分开：

| 用途 | 文件 |
|------|------|
| 围城 / `/siege spawn` | `config/fortress-besieged-clusters.json` |
| 野外集群 | `config/fortress-besieged-wilderness.json` |

缺哪个写哪个默认（阶段权重相同，野外人数更小）。已有文件不会随模组默认值自动更新；要吃到新默认请删掉对应文件后再启动。爬行类本版不做。旧稿见 [siege-cluster-templates.backup.md](siege-cluster-templates.backup.md)。

---

## 一次生成怎么抽

1. 看目标的**进度旗帜**（铁 / 钻石 + 本维恶魔区块），定阶段与哪些档位开着。持有区块数只记日志，不挡阶段。全难度同一套门槛。
2. **自然围城**再看共用值班窗口 `11000–23000`，只从已解锁的档里抽：路边 / 小股 / 一群 / 军团。地狱不在这张表。下界围城会先把路边权重清零再归一。血月期间跳过阶段 chance，到期必出一波。
3. `/siege spawn`（无值班窗）：按阶段权重抽档。下界若落在该阶段主世界窗口外则把已解锁阶段权重加总再归一（全选），并清零路边。
4. 再抽种族：主世界/末地只抽亡灵或掠夺者；**下界只抽 `nether`（烬军）**。落到对应模板。
5. 按模板掷人数、兵种、血量、移速、装备。主世界亡灵/掠夺者（不含地狱）人数看世界难度：`count` 是普通，`countByDifficulty.easy` / `hard` 分别约 ×0.6 / ×1.4（下限 3）。下界烬军与地狱模板不写覆盖。

掠夺者没有路边档：抽到路边时改抽小股。烬军有路边档；下界**围城**仍会把路边权重清零，下界**野外**保留路边。

`/siege spawn <id>` 指定模板 id 时不按维度过滤，方便调试。

**自然围城**读围城 json；**野外集群**读野外 json。野外只刷在 PBS `NATURAL` 区块，地狱档权重按 0。下界野外仍可抽路边。

野外人数比围城小：简单为路边 3–5、小股 6–8、一群/军团/地狱 10–15，普通 ×1.4、困难 ×1.9。离开自家领地后计时 600 tick，到期必试选点，不走围城值班窗。围城自然刷新间隔全难度 2000 tick。

**地狱军队**走独立调度，不出现在围城/野外阶段权重里。本维已有终末目标时，每 20 秒对每个恶魔格掷 `p=0.008`。

模板可写可选字段 `dimension`（`overworld` / `nether` / `any`）。缺省时 `race: nether` 视为下界，其余视为主世界。选择器按种族+维度过滤：下界只滚烬军，主世界/末地永不滚烬军。

## 阶段与难度

阶段不再看持有区块。解锁看原版进度，记在轮询目标 id 上（组织 UUID 或独立玩家 UUID），**只升不降**。世界难度跟原版走（`/difficulty`）：

| 原版难度 | 自然围城间隔 | 野外离境计时 | 档位门槛 |
|----------|--------------|--------------|----------|
| 和平 | 不刷 | 不刷 | — |
| 简单 | 2000 tick | 600 tick | 铁→小股；钻石→一群；钻石或恶魔格→军团 |
| 普通 | 2000 tick | 600 tick | 同简单 |
| 困难 | 2000 tick | 600 tick | 同简单 |

地狱独立波次：和平不刷，其余难度都是 400 tick + 每格 `p=0.008`，不缩放。

进度旗帜：

| 旗帜 | 进度 |
|------|------|
| 铁 | `minecraft:story/smelt_iron`（来硬的） |
| 铁甲 | `minecraft:story/obtain_armor`（整装上阵，任意铁甲） |
| 钻石 | `minecraft:story/mine_diamond` |

阶段本身（取最高已满足）：旅途始终；故土 = 铁锭；困难阶段 = 钻石；终末 = 钻石且本维有恶魔区块。全难度同一套。

组织：主人或任一成员有该进度即视为解锁。玩家进服时扫描进度。未解锁的档位不参与抽取，剩下的权重重新摊开。`worldOwned` 只作参考。

围城阶段表**不再含地狱权重**（旧默认 `hell: 0.008` 已拿去当独立调度的每格概率）：

| 阶段 | 何时进入 | 路边 | 小股 | 一群 | 军团 |
|------|----------|------|------|------|------|
| 旅途 | 还没过故土门槛 | 0.7 | 0.3 | — | — |
| 故土 | 已过故土门槛，还没钻石 | 0.2 | 0.5 | 0.3 | — |
| 困难 | 有钻石，还没有恶魔区块 | 0.05 | 0.15 | 0.3 | 0.5 |
| 终末 | 有钻石，且本维有恶魔区块 | 0.07 | 0.022 | 0.2 | 0.708 |

每一行加起来都是 1。旅途的小股权会被解锁过滤掉直到有铁（只剩路边）；困难阶段的军团权在有钻石后就会开。旅途/故土表里没有军团，所以只有恶魔格、还没钻石时仍抽不到。

自然围城用**共用值班窗口**（含 start、不含 end），路边 / 小股 / 一群 / 军团相同：

| 档位 | windowStart | windowEnd |
|------|-------------|-----------|
| 路边 / 小股 / 一群 / 军团 | 11000 | 23000 |

阶段 json 的 `spawn` 只提供 **chance**（不再挡「能不能掷」）：

| 阶段 | 主世界 chance | 期望（6 次/天） | 下界 chance（×2） |
|------|---------------|-----------------|-------------------|
| 旅途 | 0.275 | 1.65 | 0.55 |
| 故土 | 0.308 | 1.85 | 0.616 |
| 困难 | 0.342 | 2.05 | 0.684 |
| 终末 | 0.375 | 2.25 | 0.75 |

窗口时间仍写在 json 里（默认同样 11000–23000），给命令波次和下界全选判断用。站点 Bernoulli **p=0.25**。

**血月**：每个主世界日值班窗首次打开时 12.5% 开启，持续到 23000。开启时跳过上表 chance，到期必出一波。升起/结束全服血红色聊天，月亮贴图乘红色滤镜。`/siege bloodmoon start` 可强制开启。

已有 `config/fortress-besieged-*.json` 不会随模组默认自动更新；要吃新 p / 编制 / 血量 / chance 请删文件再启动。

**下界**用**主世界 `dayTime`** 对表。自然围城：值班窗 + 清零路边。`/siege spawn` 在下界且落在该阶段主世界窗口外时做全选。下界野外与主世界野外同一套离境计时，路边仍可出，地狱权重仍为 0。

地狱军队只在**恶魔区块**上出现，由 `HellSpawnScheduler` 开火，不走普通边境选点。

## 共同规则

装备表对所有**能穿能拿**的单位生效：僵尸、尸壳、骷髅等都抽同一套槽。女巫、唤魔者、劫掠兽等不能装备的，只改血量和移速。恶魂只改血量，不改移速。

头盔比胸、腿、脚更容易有货。低档仍可以大量光头，只是「有甲时先有头盔」。

围城单位不对其他怪物造成友伤，也不会被其他怪物的攻击拉仇恨。他们只打玩家一侧（玩家、铁傀、雪傀、村民、玩家宠物）。

刷出时对所属玩家发聊天「在「地区」的东南/西北…生成了集群」，方位由领土区块中心指向该生成区块。同时在生成区块吹 Seek 山羊号角。地狱波次改为全服聊天坐标。集群因全灭或（非地狱）只剩 ≤2 人解散时，进攻区块响钟，防守者再听一层挑战完成音。`/siege disband` 不播胜利。解散打 INFO。

近战伤害 = 空手攻击 + 武器加成 + 附魔。武器算进伤害。移速用原版属性（僵尸约 0.23，不是整数 2）。生命是 HP，20 即十颗心。人数至少 3。

主世界亡灵/掠夺者（不含地狱档）人数随原版难度：`count` 是普通；`countByDifficulty.easy` ×0.6、`hard` ×1.4。下界烬军与地狱模板不写覆盖，人数不随难度变。

移速**按只**从集群表掷，同兵种也可以差很多；兵种不再单独钉死。高档把权重往快的一侧推，慢的仍能抽到。路边约一成能到 `0.30`。亡灵、烬军、掠夺者同一档共用下表（掠夺者无路边，从小股起）。幼体叠原版约 +50%。恶魂跳过此表。

| 档位 | 移速（权） |
|------|------------|
| 路边 | 0.18×20，0.20×25，0.23×28，0.26×17，0.30×10 |
| 小股 | 0.20×12，0.23×25，0.26×28，0.30×22，0.33×13 |
| 一群 | 0.20×8，0.23×18，0.26×28，0.30×28，0.34×18 |
| 军团 | 0.22×8，0.25×18，0.28×27，0.32×27，0.36×20 |
| 地狱 | 0.23×6，0.26×14，0.30×28，0.34×28，0.38×24 |

| 武器 | 加成 |
|------|------|
| 木铲 / 木镐 | +1 |
| 木斧、木/金剑 | +3 |
| 铁铲 | +3.5 |
| 铁镐、石剑 | +3 / +4 |
| 铁剑 / 钻剑 / 合金剑 | +5 / +6 / +7 |
| 铁斧 | +8 |

每只怪的生成顺序：人数 → 兵种 → 血量 / 移速 / 空手攻击 → 六个装备槽 → 耐久 → 附魔。

耐久四档（各模板自己写权重）：破烂 5%–25%，磨损 25%–55%，堪用 55%–85%，接近全新 85%–100%。  
盔甲常见保护，剑常见锋利，弓常见力量。不抽亡灵杀手。

近战种不拿弓，远程种不拿剑；掠夺者只拿弩，卫道士只拿斧。**凋灵骷髅按近战**（抽 `mainHand` 剑/镐斧铲，不抽弓）；普通骷髅仍走 `mainHandRanged`。小股/一群/军团近战约一半镐斧铲（亡灵偏镐）；路边约八成工具；地狱不加镐铲。

恶魂跳过装备与破块；刷出时 Y 上移约 6–10，避免 4×4 体型卡进地面。保留原版火球 Goal；围城只 `setTarget`，不走地面 `navigation.moveTo`。

本模组刷出的僵尸猪灵（围城+野外）立即进入持久仇恨，不必先挨打。笼/刷怪笼原版猪灵不受影响。

本模组刷出的凋灵骷髅不掉 `wither_skeleton_skull`（含闪电苦力怕 100% 头颅）；煤、骨、石剑与绿宝石仍可掉。

装备掉落按原版默认 8.5% 再乘难度倍率（简单 0.6 ≈ 5.1%，普通 0.7 ≈ 6.0%，困难 0.9 ≈ 7.7%）。空槽保持 0。旗帜（掠夺者头）和副手图腾也走同一倍率。

死亡时额外掷绿宝石，不限击杀者（铁傀、摔死都算），叠在原版掉落之上（腐肉、唤魔者图腾、卫道士原版绿宝石仍在）。配置缺 `loot` 时按档位用下表；写 `"chance": 0` 可关掉。

| 档位 | 概率 | 数量 |
|------|------|------|
| 路边 | 0.5 | 1 |
| 小股 | 0.8 | 1–2 |
| 一群 | 0.9 | 1–4 |
| 军团 | 0.1 | 2–6 |
| 地狱 | 0.3 | 10–30 |

亡灵、掠夺者、烬军同一档位共用这张表。掠夺者没有路边，从小股起。烬军有路边。

## 烬军

下界专用种族 `nether`。主世界亡灵模板 `nether_wraith`（地狱亡魂）不变；熔核亡魂 id 是 `nether_ash_wraith`。

## 配置长什么样

两份文件格式相同，各自一份 `progression` + `clusters`。下面示例是**围城**默认窗口。野外根上多写 `attemptChance`（默认 1.0，调度读这个，不看阶段窗口）；缺省时用 1.0。野外 `spawn` / `netherSpawn` 仍写整天，仅作阶段表占位。

根上两块：`progression` 管阶段（含主世界 `spawn` 窗口和下界可选 `netherSpawn`），`clusters` 管军队。槽里的数字是权重；`empty` 是该槽空手。阶段权重是概率，一行加起来为 1。旧键 `hostUnlockWorldOwned` / `legionUnlockWorldOwned` 若还在会被忽略。

配置里 `unlock` 仍写 `always` / `host` / `legion`，分别对应旅途、铁进度、钻石进度。

下界到期窗口默认整天；权重用主世界 `spawn` 窗口判断「当前阶段表 vs 全选」，不必把安静时段再写一遍。`netherSpawn` 可省略，缺省为 `{ "windowStart": 0, "windowEnd": 24000, "chance": <spawn.chance × 2> }`。

可选 `dimension`：`"nether"` 只在下界抽取；省略或 `"overworld"` 只在主世界/末地。`race` 为 `nether` 时缺省即下界。

  "progression": { "stages": [ ] },
  "clusters": [ ]
}
